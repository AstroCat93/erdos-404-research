# Archived logs and witnesses

These files come from the original working directories of the six research tracks (2026-10-08).
They support the items that were **not** re-run when the note was finalised (note.md §7.3).
Each table row in §7.3 says whether a referee reproduced the item with independent code.

| path | what | used in |
|---|---|---|
| `B/landscape_p{3,5,7,11,13}.csv`, `.log` | classification of every a <= 2000 (p = 3) or a <= 1000 into BLOCKED / EXACT g / GE (g >= 10^4 by a verified witness) | §4.2 dichotomies, §4.6 |
| `B/search3_2e6.log`, `B/search7_1e6.log`, `B/verify3_2e6.log`, `B/verify7_1e6.log` | building and first verification of the f(1,3) and f(1,7) witnesses | §4.3 |
| `B/cov5.log`, `B/cov_t56.log` | earlier Cov scans (p = 5 up to t = 5, H <= 30; p = 7, 11, 13 at t = 5, 6) | §4.2 |
| `C/ecover_big.out`, `C/ecover_table.out` | covering depth L_p of the series (-1)^u/u!, including L_p >= 6 for 37 <= p <= 53 and L_p >= 5 for 59 <= p <= 97 | §3.5, §4.4 |
| `C/win2*.out` | two-block windows (p = 11, 13 and the failing levels) | §4.4 |
| `D/dfs32_c{0,1,2}.log` | p = 2 class census to G = 32 by `gdfs.c`, split into three chunks; the per-level counts must be **summed** over the three files (e.g. G = 32: 436 523 876 classes, density 0.101636) | §4.7 |
| `D/run_gclass29.log` | p = 2 BFS census (`gclass.c`) | §4.7 |
| `D/mc*.txt`, `D/first_moment_20k.txt` | Monte Carlo and first-moment experiments (heuristic only) | §5 |
| `E/tree_p*.txt`, `E/density_tables.txt` | class trees (`tree.c`) for p = 2 (to G = 29), 3 (to G = 17), 5, 7, 11, 13, 17, 19, 23 | §4.7, §4.8 |
| `F/frontier_p{3,5,7}_*` | tail-coverage frontiers (track F) | §4.5 |
| `witnesses/f1_{3,5,7}_K*.txt.gz` | explicit witnesses: increasing lists starting at 1 whose factorial sums are divisible by 3^2000001, 5^1000000, 7^1000000 | §4.3 |

Verify a witness (after `sh ../code/build.sh`):

    gunzip -k witnesses/f1_3_K2000000.txt.gz
    ../code/B/bin/verify_bin 3 1 2000001 witnesses/f1_3_K2000000.txt     # ~5 min

The p = 5 witness is the one regenerated by R4 (`sh ../code/B/run_B_witness.sh none`).
Absolute paths of the original machine have been replaced by `<workdir>` in these logs.
